# Система специальных образовательных условий для детей с РАС

Адаптивная HTML-презентация из 23 смысловых экранов. Проект подготовлен как статический сайт: для запуска не нужны сборщик, серверная часть, npm или сторонние JavaScript-библиотеки.

## Просмотр

- **На компьютере:** слайды отображаются в формате 16:9; переход между экранами — прокруткой, клавишами `↑` / `↓`, `Page Up` / `Page Down`, `Home` и `End`.
- **На телефоне:** содержание перестраивается в одну колонку; карточки и схемы сохраняют отступы и не накладываются друг на друга. Страница прокручивается естественным жестом.

## Локальный запуск

Для полного просмотра всех 23 слайдов откройте проект через локальный HTTP-сервер или GitHub Pages: заключительные слайды загружаются из `closing-slides.html`.

Для локального просмотра выполните:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохраните настройки. GitHub Pages опубликует `index.html`.

## Структура проекта

```text
ras-inclusive-education-presentation/
├── index.html                 # обложка и первые 21 экран
├── style.css                  # оформление, 16:9 и мобильная адаптация
├── script.js                  # загрузка финальных экранов, навигация и прогресс

├── preview/
│   ├── desktop-cover.png      # превью обложки на компьютере
│   └── mobile-section.png    # пример отображения на телефоне
├── .nojekyll
└── .gitignore
```
